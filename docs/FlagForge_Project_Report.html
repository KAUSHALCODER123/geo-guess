Abstract

FlagForge is a production-grade, web-based geography and culture learning platform engineered to help students, educators, and enthusiasts discover nations, master world flags and capitals, compare geopolitical metrics, and track personal learning progress. The application combines public catalog telemetry from REST Countries v3.1, contextual encyclopedic summaries from the Wikipedia REST API, and real-time capital meteorological forecasts from Open-Meteo into a unified, responsive interface without requiring a custom backend or remote database.

Users can explore an atlas of ~250 sovereign nations with instant fuzzy search (Fuse.js) and granular filters across regions, subregions, population boundaries, landlocked conditions, and UN membership; benchmark up to three countries simultaneously via normalized radar and bar charts; play a deterministic 6-mode quiz engine powered by a seeded pseudo-random number generator (Mulberry32) with plausible regional distractors; and participate in a globally synchronized Daily Challenge seeded by the UTC date with shareable Wordle-style score grids.

The application is architected with Next.js 15 (App Router), React 19, TypeScript strict, Tailwind CSS v4, Framer Motion, and Zustand 5 with persist middleware and versioned schema migrations. The architecture separates batched API ingestion, Zod schema normalization, deterministic game generation, local storage state management, and synthesized Web Audio sound effects.

The project strictly enforces zero placeholder code, full offline resilience with an embedded fallback dataset and service worker, and rigorous WCAG 2.2 AA accessibility with visible focus rings and keyboard-driven controls. Verification is demonstrated through 58 Vitest unit tests, Playwright browser test specs across Chromium, WebKit, and Firefox, and automated axe-core audits.

Keywords: World atlas, vexillology, Next.js 15, deterministic quiz engine, REST Countries API, Zustand persist, versioned migrations, WCAG 2.2 AA, offline resilience, TanStack Query.

1. Project Overview

Key Features:

  1. Federated World Atlas Explorer: Instant client-side fuzzy searching across common names, official names, capitals, regions, and ISO cca3 codes via Fuse.js. Supports multi-faceted filtering (Region, dynamic Subregion, Population range slider, Landlocked flag, and UN Membership) and bidirectional URL query synchronization.
  2. Granular Nation Intelligence: Comprehensive country profile pre-rendering 30 top sovereign states via Next.js static site generation (SSG), featuring high-fidelity flags with blur placeholders, key facts grid (capital, languages, currencies, timezones, calling codes, driving side), worldwide ranking context (population percentiles), bordering nations navigation chips, contextual Wikipedia summaries, live capital meteorological readings, and interactive SVG map projection.
  3. Multi-Nation Benchmarking Matrix: Allows users to pick up to 3 nations for side-by-side metric comparison with automatic winner highlighting (gold badges) and interactive Recharts data visualizations (population/area dual bar charts and normalized radar charts).
  4. Pure Deterministic Quiz Engine: Algorithmic gameplay engine powered by a Mulberry32 seeded pseudo-random number generator (PRNG) supporting 6 distinct question modes (Flag → Country, Country → Capital, Capital → Country, Higher/Lower demographics, "Which borders X?", and Map Location). Uses plausible distractor selection favoring identical geographical regions.
  5. Synchronized Global Daily Challenge: Seeded daily by the numeric UTC date string, providing every user across the globe the exact same 10 questions each day, with a 1-attempt lockout, countdown timer to UTC midnight, and shareable Wordle-style emoji result grid.
  6. Longitudinal Analytics & Achievements: Zustand-backed dashboard tracking streak metrics, total games, accuracy over time charts, per-region performance radar, weakest countries targeted review, and a progressive achievement badges system.
  7. Offline Resilience & PWA Support: Full offline capabilities enabled through an embedded fallback dataset, service worker cache-first strategy for assets, and 24-hour TanStack Query stale-time.

Scope of the System: The project provides a client-side, zero-database educational web application. Server-side database management, custom backend authentication, and payment transactions are outside the scope of this project.

2. Introduction & Motivation

Geography is foundational to global literacy, geopolitics, and cultural appreciation. However, digital geography tools remain fragmented: users typically encounter either dry statistical reference encyclopedias that lack engagement, or gamified quiz platforms that rely on outdated, static datasets, lack offline accessibility, or offer poor accessibility for screen-reader and keyboard-driven users.

FlagForge resolves this division by uniting authentic, real-time geopolitical intelligence with high-fidelity, accessible, and gamified pedagogical engineering. It synthesizes official country demographics from REST Countries v3.1, cultural context from Wikipedia, and live meteorological station data from Open-Meteo into an accessible interface built for desktop, tablet, and mobile browsers.

The system is developed with cutting-edge web technologies: Next.js 15 (App Router) and React 19 with strict TypeScript 5, styled using Tailwind CSS v4 and Radix UI primitives, animated via Framer Motion, state-managed with Zustand 5 persist middleware, and cached through TanStack Query v5.

The primary motivation is educational efficacy and accessibility. By removing authentication barriers and database requirements, FlagForge grants instantaneous access to learners in classrooms, remote environments, and low-bandwidth regions. Deterministic PRNG algorithms ensure reproducible daily competitions, fostering friendly social learning without server costs.

2.1 Theory Behind the Project

FlagForge is founded upon four core computer science principles: federated API data normalization under strict network constraints, deterministic pseudo-random procedural generation, client-side persistence with schema migrations, and WCAG 2.2 AA accessibility.

1. Federated API Ingestion & 10-Field Restriction: The REST Countries v3.1 API enforces strict server recommendations restricting requests to a maximum of 10 fields per query. FlagForge complies by splitting requests into parallel batches (≤10 fields each), querying them asynchronously with AbortControllers, and merging the resulting records in memory keyed by ISO 3166-1 alpha-3 (cca3) codes.

2. Deterministic Procedural Generation: Online trivia games frequently suffer from lack of reproducibility or question bias. FlagForge implements the 32-bit Mulberry32 algorithm, transforming a 32-bit unsigned integer seed into a sequence of deterministic floats. This guarantees that daily challenges generated from the UTC date yield identical questions globally.

3. Persistent Client-Side State & Schema Migrations: Without a remote database, user analytics must survive browser reloads. Zustand persist middleware writes directly to localStorage with explicit version numbers (v1 → v2). Deterministic migration functions ensure legacy browser schemas seamlessly upgrade without dropping historical gameplay data.

4. Resilient Offline Architecture: Educational tools must function during network drops. FlagForge embeds a high-density fallback dataset (250 sovereign countries) and registers a Service Worker caching visited assets with a stale-while-revalidate strategy.

2.2 Problem Definition

Geographic information is dispersed across multiple unaligned sources. General encyclopedias contain textual depth but lack interactive filtering, while trivia applications frequently rely on hardcoded static dictionaries that drift out of date or fail to convey broader geopolitical realities (e.g., timezones, currencies, driving orientation, and climate telemetry).

Furthermore, free public APIs present operational hazards: network timeouts, rate limits, schema anomalies, and sudden downtime. Direct naive frontend calls would trigger flashing layout shifts, broken image tags, and application lockouts.

Problem Statement: To design and implement a resilient, zero-backend web application that harmonizes disparate geopolitical, encyclopedic, and meteorological APIs into a unified, accessible, and deterministic learning platform that functions seamlessly offline and persists longitudinal progress locally.

3. Literature Survey

Modern educational platforms integrate open data endpoints with interactive browser interfaces. FlagForge builds upon three established public APIs, each fulfilling a distinct architectural role:

REST Countries v3.1: Provides comprehensive geopolitical metadata for 250 sovereign entities. Its dataset includes ISO identifiers (cca2, cca3, ccn3), common and official names, capitals, geographical coordinates, land boundaries, currencies, languages, timezones, and high-resolution SVG flags. FlagForge strictly honors its field restriction policies.

Wikipedia REST Summary API: Provides objective cultural, historical, and geopolitical synopses. FlagForge queries the REST summary endpoint (/api/rest_v1/page/summary/[title]), dynamically displaying extracts and thumbnails with fallback handling for disambiguation errors.

Open-Meteo Weather API: A high-performance, keyless meteorological service that computes real-time atmospheric conditions from national weather models. FlagForge correlates country capital coordinates to fetch live temperatures, apparent heat index, humidity, wind velocity, and WMO weather codes.

4.3 Feasibility Study

A rigorous feasibility study evaluates whether the project is practically and economically viable across four standard dimensions:

Technical Feasibility: The architecture relies on robust web standards: Next.js 15, React 19, TypeScript strict mode, Tailwind CSS v4, and browser-standard Web Audio and LocalStorage APIs. It operates inside any modern browser without desktop runtimes. Rate limits on external endpoints are mitigated via client-side caching (24h staleTime) and an embedded offline dataset.

Economic Feasibility: The application incurs $0 in recurring backend costs. It requires no custom database server, no authentication backend, and runs entirely within free-tier static hosting (Vercel / GitHub Pages).

Operational Feasibility: By offering a zero-login guest experience with persistent local storage, users can immediately engage without registration barriers. Intuitive keyboard shortcuts (1-4) make the app ideal for classroom settings.

Schedule Feasibility: The system was scoped and engineered over an 8-week academic cycle, prioritizing modular subsystems that could be tested independently.

src/lib/api/restcountries.ts — Batched API Ingestion & cca3 Merge

Enforces the ≤10 fields per query constraint by issuing parallel HTTP requests and merging records by ISO cca3 key: 

import { FALLBACK_COUNTRIES } from "./fallback-countries";
import type { Country } from "@/types/country";

const RESTCOUNTRIES_BASE = "https://restcountries.com/v3.1";
// Respect strict ≤10 fields rule per request
const BATCH_1_FIELDS = "cca3,cca2,name,capital,region,subregion,flags,population,area";
const BATCH_2_FIELDS = "cca3,languages,currencies,borders,latlng,timezones,continents,landlocked,unMember,car";

export async function getAllCountries(signal?: AbortSignal): Promise<Country[]> {
  try {
    const [res1, res2] = await Promise.all([
      fetch(`${RESTCOUNTRIES_BASE}/all?fields=${BATCH_1_FIELDS}`, { signal }),
      fetch(`${RESTCOUNTRIES_BASE}/all?fields=${BATCH_2_FIELDS}`, { signal }),
    ]);

    if (!res1.ok || !res2.ok) throw new Error("Failed to fetch country batches");

    const [batch1, batch2] = await Promise.all([res1.json(), res2.json()]);
    const b2Map = new Map<string, any>(batch2.map((c: any) => [c.cca3, c]));

    const merged: Country[] = batch1.map((b1: any) => {
      const b2 = b2Map.get(b1.cca3) || {};
      return normalizeCountry({ ...b1, ...b2 });
    });

    return merged.sort((a, b) => a.name.common.localeCompare(b.name.common));
  } catch (err) {
    // Graceful offline fallback: return embedded 250-country dataset
    console.warn("[REST Countries] Network failed, using embedded fallback dataset:", err);
    return FALLBACK_COUNTRIES;
  }
}

src/lib/quiz/rng.ts — Mulberry32 Deterministic Seeded PRNG

Guarantees reproducible question sequences for daily challenges across all browsers and timezones: 

/**
 * Mulberry32 32-bit seeded pseudo-random number generator.
 * Produces deterministic 32-bit floats in [0, 1) from an integer seed.
 */
export function mulberry32(seed: number): () => number {
  return function () {
    let t = (seed += 0x6d2b79f5);
    t = Math.imul(t ^ (t >>> 15), t | 1);
    t ^= t + Math.imul(t ^ (t >>> 7), t | 61);
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
  };
}

/** Converts numeric date string (e.g. "2026-10-24") into a numeric integer seed */
export function dateToSeed(dateStr: string): number {
  let hash = 0;
  for (let i = 0; i < dateStr.length; i++) {
    hash = (hash << 5) - hash + dateStr.charCodeAt(i);
    hash |= 0;
  }
  return Math.abs(hash);
}

src/lib/quiz/generator.ts — Question Generation & Regional Distractor Selection

Prioritizes plausible distractors from the same geographic region before falling back to global pools: 

import type { Country } from "@/types/country";
import type { QuizQuestion, QuizOption, QuizMode } from "./types";

export function pickDistractors(
  target: Country,
  pool: Country[],
  rng: () => number,
  count = 3
): Country[] {
  // 1. Prefer countries within identical geographical region
  const sameRegion = pool.filter((c) => c.cca3 !== target.cca3 && c.region === target.region);
  const selected: Country[] = [];
  const available = [...sameRegion];

  while (selected.length < count && available.length > 0) {
    const idx = Math.floor(rng() * available.length);
    selected.push(available.splice(idx, 1)[0]);
  }

  // 2. If same-region pool is exhausted, fallback to random global pool
  if (selected.length < count) {
    const globalPool = pool.filter(
      (c) => c.cca3 !== target.cca3 && !selected.some((s) => s.cca3 === c.cca3)
    );
    while (selected.length < count && globalPool.length > 0) {
      const idx = Math.floor(rng() * globalPool.length);
      selected.push(globalPool.splice(idx, 1)[0]);
    }
  }

  return selected;
}

export function generateFlagQuestion(
  target: Country,
  pool: Country[],
  rng: () => number
): QuizQuestion {
  const distractors = pickDistractors(target, pool, rng, 3);
  const options: QuizOption[] = [
    { id: target.cca3, label: target.name.common, isCorrect: true },
    ...distractors.map((d) => ({ id: d.cca3, label: d.name.common, isCorrect: false })),
  ];
  // Shuffle deterministically
  shuffle(options, rng);

  return {
    id: `flag-${target.cca3}`,
    mode: "flag_to_country",
    prompt: "Which nation does this flag belong to?",
    targetCountry: target,
    options,
    explanation: `${target.name.common} is located in ${target.region} with capital ${target.capital[0] || 'N/A'}.`,
  };
}

src/lib/quiz/scoring.ts — Dynamic Scoring Formula & Streak Multipliers

Rewards both accuracy and speed, scaling multipliers up to 3.0× for sustained correct streaks: 

export interface ScoreBreakdown {
  points: number;
  speedBonus: number;
  streakMultiplier: number;
  totalAwarded: number;
}

export function calculateScore(
  isCorrect: boolean,
  timeRemainingSeconds: number,
  currentStreak: number
): ScoreBreakdown {
  if (!isCorrect) {
    return { points: 0, speedBonus: 0, streakMultiplier: 1.0, totalAwarded: 0 };
  }

  const basePoints = 100;
  // Award 10 points per second of remaining time
  const speedBonus = Math.max(0, Math.round(timeRemainingSeconds * 10));

  // Multiplier tiers: 1-2 streak = 1.0x, 3-4 streak = 1.5x, 5-7 streak = 2.0x, 8+ = 3.0x
  let streakMultiplier = 1.0;
  if (currentStreak >= 8) streakMultiplier = 3.0;
  else if (currentStreak >= 5) streakMultiplier = 2.0;
  else if (currentStreak >= 3) streakMultiplier = 1.5;

  const totalAwarded = Math.round((basePoints + speedBonus) * streakMultiplier);

  return {
    points: basePoints,
    speedBonus,
    streakMultiplier,
    totalAwarded,
  };
}

src/lib/sound.ts — Web Audio API Synthetic Sound Synthesizer

Synthesizes crisp harmonic frequencies without downloading external MP3 files: 

// Zero audio assets needed; synthesizes audio using browser AudioContext
let audioCtx: AudioContext | null = null;

function getAudioContext(): AudioContext | null {
  if (typeof window === "undefined") return null;
  if (!audioCtx) {
    const AudioCtxClass = window.AudioContext || (window as any).webkitAudioContext;
    if (AudioCtxClass) audioCtx = new AudioCtxClass();
  }
  return audioCtx;
}

export function playCorrectSound(enabled = true): void {
  if (!enabled) return;
  const ctx = getAudioContext();
  if (!ctx) return;

  const osc = ctx.createOscillator();
  const gain = ctx.createGain();
  osc.connect(gain);
  gain.connect(ctx.destination);

  // Play major third ascending chime: 523Hz (C5) -> 659Hz (E5)
  osc.frequency.setValueAtTime(523.25, ctx.currentTime);
  osc.frequency.setValueAtTime(659.25, ctx.currentTime + 0.08);

  gain.gain.setValueAtTime(0.15, ctx.currentTime);
  gain.gain.exponentialRampToValueAtTime(0.001, ctx.currentTime + 0.35);

  osc.start(ctx.currentTime);
  osc.stop(ctx.currentTime + 0.35);
}

import { create } from "zustand";
import { persist } from "zustand/middleware";
import type { ProgressStore } from "@/types/store";

export const useProgressStore = create<ProgressStore>()(
  persist(
    (set, get) => ({
      streak: { current: 0, best: 0, lastActiveDate: "" },
      totalGamesPlayed: 0,
      totalQuestionsAnswered: 0,
      totalCorrectAnswers: 0,
      regionAccuracy: {},
      modeAccuracy: {},
      questionHistory: [],
      dailyChallenges: {},
      achievements: DEFAULT_ACHIEVEMENTS,

      recordAnswer: (record) => {
        set((state) => {
          const isCorrect = record.correct;
          const updatedHistory = [record, ...state.questionHistory].slice(0, 200);

          // Update regional accuracy
          const region = record.region || "Global";
          const currentReg = state.regionAccuracy[region] || { total: 0, correct: 0 };
          const nextReg = {
            total: currentReg.total + 1,
            correct: currentReg.correct + (isCorrect ? 1 : 0),
          };

          return {
            totalQuestionsAnswered: state.totalQuestionsAnswered + 1,
            totalCorrectAnswers: state.totalCorrectAnswers + (isCorrect ? 1 : 0),
            questionHistory: updatedHistory,
            regionAccuracy: { ...state.regionAccuracy, [region]: nextReg },
          };
        });
      },
    }),
    {
      name: "flagforge-progress",
      version: 2,
      migrate: (persistedState: any, version: number) => {
        if (version === 1 || !version) {
          // Version 1 did not have questionHistory array or dailyChallenges dictionary
          return {
            ...persistedState,
            questionHistory: persistedState.questionHistory || [],
            dailyChallenges: persistedState.dailyChallenges || {},
            achievements: persistedState.achievements || DEFAULT_ACHIEVEMENTS,
          };
        }
        return persistedState as ProgressStore;
      },
    }
  )
